# toolkit

Консольный набор утилит: калькулятор арифметических выражений и конвертер единиц измерения.

## Установка

```bash
uv sync
source .venv/bin/activate
pre-commit install
```

## Запуск

```bash
uv run python -m toolkit calc "10/4 + 2"
uv run python -m toolkit convert 36.6 --from c --to f
```

Справка: `python -m toolkit --help`, `python -m toolkit calc --help`.

### calc

```text
$ python -m toolkit calc "10/4 + 2"
4.5
$ python -m toolkit calc "-7 // 3"
-3
$ python -m toolkit calc "2 ** 100"
1.2677e+30
```

Выражение нужно брать в кавычки. Поддерживаются числа, скобки, операторы `+ - * / // % **` и унарные `+`, `-`. Приоритет: `+ -` ниже `* / // %`, выше них унарные знаки, самый высокий у `**`. Оператор `**` правоассоциативен, поэтому `2 ** 3 ** 2` равно 512, а `-2 ** 2` равно -4. Выражение, начинающееся с минуса (`calc "-5+2"`), работает без `--`.

Вычисления идут в `Decimal`, поэтому `0.1 + 0.2` даёт ровно `0.3`. Операторы `//` и `%` считаются по правилам математики — остаток всегда >= 0 и < модуля делителя.

### convert

```text
$ python -m toolkit convert 36.6 --from c --to f
97.88
$ python -m toolkit convert 1500 --from g --to kg
1.5
```

Единицы (регистр не важен):

| Группа      | Единицы               |
|-------------|-----------------------|
| Длина       | `mm`, `cm`, `m`, `km` |
| Масса       | `g`, `kg`             |
| Температура | `c`, `f`, `k`         |

Переводить можно только внутри одной группы. Запись через `e` не принимается. Отрицательное значение можно писать сразу после `convert`: `convert -5. --from c --to f`.

Длина и масса не бывают отрицательными, температура не может быть ниже абсолютного нуля.

## Формат результата

Результат округляется до 4 знаков после точки (половина — вверх), лишние нули и точка в конце убираются, `-0` печатается как `0`. Если модуль результата не меньше 10^15, он печатается в экспоненциальной форме с 4 знаками: `1.2677e+30`.

## Ошибки

Ошибка ввода или вычисления печатается в stderr в виде `Ошибка: <причина>`, код выхода 2. Ошибки разбора аргументов (например, `calc` без выражения) тоже завершаются кодом 2. При успехе код выхода 0.

## Ограничения

- Калькулятор считает с точностью 28 значащих цифр.
- Выражение `0 ** 0`, возведение отрицательного числа в нецелую степень и слишком большие степени дают `Ошибка: Ошибка вычисления`.
- Конвертер использует `float`, поэтому результат приближённый. Числа, не помещающиеся во `float`, дают ошибку «Слишком большое число».
- Экспоненциальной записи нет.

## Структура проекта

```text
src/toolkit/
    __main__.py    точка входа для python -m toolkit
    main.py        разбор аргументов и вывод
    calculator.py  токенизация, проверка, RPN, вычисление, форматирование
    converter.py   разбор значения и перевод единиц
    constants.py   все константы и таблицы
    errors.py      ToolkitError и подошибки
tests/
    test_calculator.py
    test_converter.py
    test_cli.py
```

## Проверки

```bash
uv run pytest --cov=toolkit
uv run ruff check .
uv run mypy src tests
```

Тесты командной строки запускают программу в отдельном процессе, поэтому покрытие `main.py` и `__main__.py` в отчёте pytest-cov не учитывается (0%). Покрытие `calculator.py` и `converter.py` 100%.
